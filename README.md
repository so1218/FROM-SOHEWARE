## 概要 (Overview)
GE3 は、〇〇を目的としてC++で開発された軽量なゲームエンジンです。
DirectXTexやAssimpを統合しており、直感的な記述で3D/2Dの描画セットアップが完了します。

## 特徴 (Features)
- 🎮 **シンプルな設計**: 複雑な設定なしで、すぐにゲームループを構築可能
- 📦 **外部ライブラリの統合**: DirectXTex, Assimp に標準対応
- 🔧 **モダンC++**: C++17の機能を活用した安全で読みやすいコードベース

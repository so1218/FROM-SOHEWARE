# はじめに

ビルドして起動し、エディター画面で何ができるかを確認します。ここまでで 15 分ほどです。

## 必要なもの

| 項目 | 内容 |
| :--- | :--- |
| OS | Windows 10 / 11 (64 bit) |
| 開発環境 | Visual Studio 2026 (「C++ によるデスクトップ開発」をインストールしたもの。プラットフォームツールセット v145 を使う) |
| GPU | DirectX 12 に対応したもの |

## ビルドして起動する

1. ゲームのソリューション (`.slnx`) を Visual Studio で開く。まだゲームがないときは、先に [新しいゲームを始める](new-project.md) の手順で作る
2. 上部のビルド構成で **Development** を選ぶ
3. F5 (デバッグ開始) で実行する

初回は、シェーダーのコンパイルとテクスチャの変換を行うので起動に時間がかかります。2 回目からは `Cache/` に保存された結果を使うので速くなります。

### ビルド構成の選び方

| 構成 | 使う場面 |
| :--- | :--- |
| **Development** | 普段のゲーム作り。最適化されていて速く、エディター画面も使える |
| **Debug** | エンジンの不具合を調べるとき。遅いが、DirectX 12 のエラーやメモリリークを詳しく報告する |
| **Release** | 完成版の確認と配布。ログやエラー表示が減り、全画面で起動する |

:::{warning}
Release はシェーダーをその場でコンパイルせず、`Cache/Shaders/` の結果だけを使います。シェーダーを変更したら、Release で起動する前に Development で一度起動してください。
:::

## エディター画面の使い方

開発用の構成 (Debug・Development) で起動すると、ゲーム画面のまわりに調整用のウィンドウが並んだ「エディター画面」になります。

| 操作 | 内容 |
| :--- | :--- |
| **F1** | エディター画面とゲーム画面 (全画面) を切り替える |
| **Y** | デバッグカメラの ON / OFF (エディター画面のときだけ) |

よく使うウィンドウは次のとおりです。

| ウィンドウ | できること |
| :--- | :--- |
| シーンの選択 | 登録されているシーンに切り替える |
| パラメータの保存 | 調整した値を JSON に保存する。「すべての変更を保存」を押すまで保存されない |
| 全体のデバッグ情報・設定 | FPS の確認、デバッグカメラ・デバッグ描画・一時停止の切り替え |
| (シーン名のウィンドウ) | カメラ・ライト・ポストエフェクトなど、シーンごとの設定 |
| パーティクルエディター | エフェクトのプリセットを編集・保存する |
| 開発用のエラー | 名前の書き間違いなど、直すべき間違いの一覧。間違いがあるときだけ出る |

### デバッグカメラの操作

ゲーム画面 (Scene ウィンドウ) の上にマウスを置いて操作します。

| 操作 | 内容 |
| :--- | :--- |
| 中ボタンドラッグ | 注視点のまわりを回る |
| Shift + 中ボタンドラッグ | 平行移動 |
| ホイール | 近づく・離れる |

## フォルダ構成

```text
MyGame/
├── Engine/          エンジン (直接は直さない)
│   ├── Docs/            このドキュメント
│   ├── Shaders/         シェーダー
│   ├── Assets/          エンジンが使うテクスチャ・モデル・フォント・描画の設定
│   ├── externals/       外部ライブラリ (ImGui・DirectXTex・assimp など)
│   └── Template/        新しいゲームのひな形
├── Game/            ゲームのコード (シーン・オブジェクト・入力の割り当てなど)
├── Assets/          ゲームのモデル・テクスチャ・音・保存したパラメータ
├── generated/       ビルド結果 (exe・中間ファイル)
├── Cache/           シェーダーとテクスチャの変換結果 (消しても次の起動で作り直される)
└── logs/            実行ログ
```

ゲームを作るときに触るのは、基本的に `Game/` と `Assets/` だけです。

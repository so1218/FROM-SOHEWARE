# アセットの追加

モデル・テクスチャ・音は、`Assets/` の決まったフォルダに置くだけで、起動時に自動で読み込まれます。登録の作業はいりません。
コードからは **ファイル名 (拡張子なし)** で使います。

| 種類 | 置く場所 | 形式 | コードでの使い方 |
| :--- | :--- | :--- | :--- |
| 3D モデル | `Assets/Models/` | `.gltf` `.obj` | `Model(engine, "名前")` |
| アニメーション | `Assets/Models/` | `.gltf` (メッシュなし) | `AnimationModel(engine, "モデル名", "アニメ名")` |
| テクスチャ | `Assets/Textures/<種類>/` | `.png` `.jpg` `.tga` `.dds` | `SetTexture("名前")` |
| 音 | `Assets/Audio/` | `.mp3` `.wav` | `AudioPlayer::GetInstance().Play("名前")` |
| フォント | `Assets/Data/Fonts/` + `FontList.csv` | `.ttf` | `Text(engine, "FontList.csv の Name")` |
| パーティクル | `Assets/Data/Particle/` | `.json` | `SpawnEmitter("名前")` |

`Assets/` の中ではサブフォルダを自由に作れます (`Models/Characters/Enemy/` など)。

エンジン自体が使うアセット (白いテクスチャ・空のキューブマップ・基本図形のモデル・エディターのフォントなど) は、`Engine/Assets/` にあります。読み込み方はゲームのアセットと同じで、ゲームからも同じように名前で使えます。エンジンを改造するとき以外は触らないでください。

:::{important}
**名前はファイル名だけで決まります。** フォルダが違っても、同じ種類で同じ名前のファイルがあると片方しか読まれません。
`Engine/Assets/` を先に読むので、エンジンのアセットと同じ名前のファイルを `Assets/` に置いても使われません。
テクスチャの名前は、大文字と小文字を区別しません。
:::

## 3D モデル

- glTF (`.gltf` + `.bin`) か OBJ (`.obj` + `.mtl`) で置く
- **モデルファイルの中で指定したテクスチャは使われない。** 最初は白で表示されるので、テクスチャは `Assets/Textures/` に置き、`SetTexture` かエディター画面 (`BindModel`) で付ける
- 1 つのモデルに複数のマテリアルがあってもよい。マテリアルごとの色やテクスチャはエディター画面で調整できる ([3D モデルとアニメーション](model.md))
- 大きさ・向きはモデルを作ったツールの設定がそのまま使われる。1 単位 = 1 m を目安にそろえておくと、当たり判定や移動速度の数値が決めやすい

## アニメーション

- メッシュを含まず、アニメーションだけを含む glTF として置く。メッシュを含むファイルはモデルとして読まれる
- 1 ファイルに 1 アニメーション。ファイル名がアニメーション名になる
- アニメーションを付けるモデルと、ボーンの名前と構造が同じでなければならない (Mixamo なら同じキャラクターで書き出す)

## テクスチャ

テクスチャは、置いたフォルダで種類が決まります。法線マップを `albedo/` に置くと色の扱いが変わり、正しく光らないので注意してください。

| フォルダ | 種類 |
| :--- | :--- |
| `albedo/` `Utility/` | 色のテクスチャ |
| `Normal/` | 法線マップ |
| `UI/` | UI 用の画像 |
| `Particles/` | パーティクル用の画像 |
| `Noise/` | ノイズ (シェーダーの効果用) |
| `Ramps/` | トゥーン用のグラデーション |
| `Environments/` | 空や反射用のキューブマップ (`.dds`) |

上のどれでもないフォルダに置いたものは色のテクスチャとして扱います。ただし、ファイル名が `_n` か `_normal` で終わるものは法線マップとして扱います。

初回の起動で `.dds` に変換されて `Cache/Textures/` (エンジンのテクスチャは `Cache/EngineTextures/`) に保存され、2 回目からはそれを読みます。

## 音

- `Assets/Audio/` の中ならどこでもよい。今は効果音を `SE/`、BGM を `BGM/` に置いている
- 鳴らし方は [音](audio.md)

## フォント

1. `.ttf` を `Assets/Data/Fonts/` に置く
2. `Assets/Data/FontList.csv` に 1 行足す

詳しくは [UI (画像と文字) のフォントを足す](ui.md#フォントを足す) を見てください。

## 保存されるデータ

エディター画面で保存したものは、すべて `Assets/Data/` の下に JSON で書かれます。Git で管理して、チームで共有してください。

| フォルダ | 内容 |
| :--- | :--- |
| `Assets/Data/GlobalVariables/` | PropertyBinder で保存した値。保存先の名前ごとに 1 ファイル |
| `Assets/Data/Particle/` | パーティクルのプリセット |

描画の設定 (シェーダーとブレンドなどの組み合わせ) はエンジンのデータなので、`Engine/Assets/Data/PSODefinitions/` にあります。

## つまずきやすい点

- **追加したのに出ない。** アセットは起動時にしか読まれない。起動し直す
- **名前が見つからない。** 「開発用のエラー」ウィンドウに、探した名前と、それを書いた場所が出る
- **テクスチャを差し替えたのに古いまま。** 変換結果は、元の画像の方が新しいときだけ作り直される。更新日時の古いファイルで上書きしたときは、`Cache/Textures/` の同じ名前の `.dds` を消して起動し直す

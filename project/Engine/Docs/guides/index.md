# 機能別ガイド

やりたいことが決まっているときに読む手順書です。どのページも「基本の使い方」→「よく使う設定」→「つまずきやすい点」の順に書いています。
関数を 1 つずつ説明することはせず、ゲームを作るのに必要なものだけを載せています。全部の関数を見たいときは [API リファレンス](../reference/api.md) を使ってください。

## ゲームの骨組み

| ページ | こんなときに読む |
| :--- | :--- |
| [シーン](scene.md) | タイトル画面・ゲーム画面などを作って切り替えたい |
| [GameObject](gameobject.md) | キャラクターやアイテムを作りたい。ほかのオブジェクトを探したい・消したい |
| [入力](input.md) | キーボード・マウス・パッドで操作したい。操作を足したい |
| [パラメータの調整と保存](parameters.md) | 数値や色をエディター画面で調整して保存したい |

## 見た目と音

| ページ | こんなときに読む |
| :--- | :--- |
| [3D モデルとアニメーション](model.md) | モデルを出したい。色を変えたい。アニメーションを再生したい |
| [UI (画像と文字)](ui.md) | HP ゲージやスコアなど、画面に画像や文字を出したい |
| [カメラ](camera.md) | キャラクターを追うカメラを作りたい。画面を揺らしたい |
| [エフェクトとライト](effects.md) | パーティクルを出したい。明かりを置きたい。時間帯や天気を変えたい |
| [音](audio.md) | 効果音や BGM を鳴らしたい |

## 当たり判定とデータ

| ページ | こんなときに読む |
| :--- | :--- |
| [当たり判定](collision.md) | 触れたら何か起こしたい。弾が当たったか調べたい |
| [アセットの追加](assets.md) | モデル・画像・音・フォントを足したい |
| [デバッグ](debugging.md) | うまく動かない原因を調べたい |

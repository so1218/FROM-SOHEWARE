# 5. スコアを表示する

画面の左上に「ジェム 3 / 8」のようにスコアを出します。

## シーンに Text を持たせる

画面に文字を出すには `FS::Text` を使います。今回は、シーンがボールのスコアを読んで表示します。

`SampleScene.h` を次のように変えます。

```cpp
#pragma once
#include "BaseScene.h"
#include "Text.h"

class Ball;

class SampleScene : public FS::BaseScene
{
public:
    SampleScene(FS::Engine* engine);

protected:
    void OnInitialize() override;
    void OnUpdate() override;
    void OnDraw() override;

private:
    Ball* ball_ = nullptr;
    std::unique_ptr<FS::Text> scoreText_;
};
```

`SampleScene.cpp` を次のように変えます。

```cpp
SampleScene::SampleScene(Engine* engine)
    : BaseScene(engine, SceneName::Sample)
{
    objectManager_.Create<Environment>(engine_);
    objectManager_.Create<Grid>(engine_);

    // Create は作ったオブジェクトのポインタを返す。あとでスコアを読むので覚えておく
    ball_ = objectManager_.Create<Ball>(engine_);

    for (int i = 0; i < 8; ++i)
    {
        const float angle = Math::PI * 2.0f * static_cast<float>(i) / 8.0f;
        objectManager_.Create<Gem>(engine_, Vector3{ std::cos(angle) * 6.0f, 1.0f, std::sin(angle) * 6.0f });
    }

    // 画面の左上から右に 20、下に 20 ずらした位置に出す
    scoreText_ = std::make_unique<Text>(engine_);
    scoreText_->SetAnchor(UIAnchor::TopLeft);
    scoreText_->SetPosition({ 20.0f, 20.0f });
    scoreText_->SetFontSize(32.0f);
}

void SampleScene::OnUpdate()
{
    scoreText_->SetText(std::format("ジェム {} / 8", ball_->GetScore()));
}

void SampleScene::OnDraw()
{
    scoreText_->Draw();
}
```

- `OnUpdate()` と `OnDraw()` は毎フレーム呼ばれる。シーンに置いたオブジェクトの `Update()` / `Draw()` とは別に、シーン自身の処理を書く場所
- UI の位置は、画面の高さを 720 とした単位で指定する。解像度が変わっても、同じ見た目になるように自動で拡大される
- `SetAnchor(UIAnchor::TopRight)` にすると、右上を基準に置ける。画面の端に寄せる UI はアンカーを使うと崩れない

## 動かしてみる

ジェムを拾うたびに、左上の数字が増えれば完成です。

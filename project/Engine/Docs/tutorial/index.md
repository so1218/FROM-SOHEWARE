# チュートリアル: ジェム集めゲームを作る

ボールを転がして、まわりに置いたジェムを集めるだけの小さなゲームを作ります。
エンジンでゲームを作るときに毎回使う、次のことを一通り体験できます。

- シーンを作って登録する
- GameObject を作り、モデルを表示して入力で動かす
- 調整したい値をエディター画面に出して保存する
- 当たり判定で「拾う」を作る
- 画面に文字を出す
- 効果音とエフェクトを付ける

| ステップ | 作るもの |
| :--- | :--- |
| [1. シーンを作る](01-scene.md) | 空と床だけの空っぽのシーン |
| [2. ボールを動かす](02-ball.md) | キーボード・パッドで動くボール |
| [3. 値をエディターで調整する](03-tuning.md) | ボールの速さをゲームを止めずに変えて保存する |
| [4. ジェムを拾う](04-gem.md) | 触れると消えるジェムとスコア |
| [5. スコアを表示する](05-ui.md) | 画面左上のスコア表示 |
| [6. 音とエフェクトを付ける](06-polish.md) | 拾ったときの効果音と光 |

各ステップの終わりで、ビルドして動きを確認できるようにしてあります。
説明は最小限にしているので、気になったところは各ステップの最後にある「詳しく知りたいとき」のガイドを読んでください。

## 始める前に

- [はじめに](../start/index.md) を読んで、Development 構成でビルド・起動できる状態にしておいてください
- コードはすべて `Game/` の中に作ります

:::{note}
新しく作った `.h` / `.cpp` は、Visual Studio のソリューションエクスプローラーで右クリック →「追加」→「既存の項目」からプロジェクトに追加してください。
ファイルを置くのは、このチュートリアルで指定する既存のフォルダにしてください。新しいフォルダを作ると、インクルードディレクトリへの追加が必要になります ([コードの決まり](../concepts/conventions.md#新しいファイルとフォルダを追加する))。
:::

# チュートリアル: ジェム集めゲームを作る

ボールを転がして、まわりに置いたジェムを集める小さなゲームを作ります。
エンジンでゲームを作るときに毎回使う、次のことを一通り体験できます。

- シーンを作って登録する
- GameObject を作り、モデルを表示して入力で動かす
- 調整したい値をエディター画面に出して保存する
- 当たり判定で「拾う」を作る
- 画面に文字を出す
- 効果音とエフェクトを付ける

| ステップ | 作るもの |
| :--- | :--- |
| [1. シーンを作る](01-scene.md) | 空と床だけのシーン |
| [2. ボールを動かす](02-ball.md) | キーボード・パッドで動くボール |
| [3. 値をエディターで調整する](03-tuning.md) | ボールの速さを、ゲームを止めずに変えて保存する |
| [4. ジェムを拾う](04-gem.md) | 触れると消えるジェムとスコア |
| [5. スコアを表示する](05-ui.md) | 画面左上のスコア表示 |
| [6. 音とエフェクトを付ける](06-polish.md) | 拾ったときの効果音と光 |

各ステップの終わりで、ビルドして動きを確認できます。
説明は最小限にしているので、気になったところは各ステップの最後にある「詳しく知りたいとき」のガイドを読んでください。

## 始める前に

[新しいゲームを始める](../start/new-project.md) の手順で作ったゲームが、Development でビルド・起動できる状態から始めます。
コードはすべて `Game/` の中に、素材は `Assets/` の中に作ります。`Engine/` の中は変えません。

### GameObject 用のフォルダを用意する

このチュートリアルでは、ボールやジェムのクラスを `Game/GameObject/` に置きます。
`#include` はフォルダ名を付けずにファイル名だけで書くので、ヘッダーを置くフォルダは「インクルードディレクトリ」に登録されている必要があります。

1. `Game/GameObject` フォルダがなければ、エクスプローラーで作る
2. ソリューションエクスプローラーで `Game` プロジェクトを右クリック →「プロパティ」を開く
3. 上の「構成」を「すべての構成」にする
4. 「C/C++」→「全般」→「追加のインクルードディレクトリ」に `$(ProjectDir)Game\GameObject` があるか確認する。なければ、`;` で区切って最後に足す

新しいひな形 (エンジン v1.0.2 以降) から始めたゲームには、最初から登録されています。

### ファイルの足し方

新しく作った `.h` / `.cpp` は、ファイルを作ったあと、ソリューションエクスプローラーで `Game` を右クリック →「追加」→「既存の項目」でプロジェクトに追加します。
追加しないと、`.cpp` がコンパイルされず「未解決の外部シンボル」のエラーになります。

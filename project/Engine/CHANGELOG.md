# 変更履歴

版ごとの変更点です。ゲーム側で対応が必要な変更は「対応が必要」に書きます。

## 未リリース

最初の版です。

### できること
- 3D モデル・スキニングアニメーション・地形・草・木・空・天気・パーティクル・トレイル・雷の描画
- 影・SSAO・ブルーム・被写界深度・ボリュメトリックフォグなどの画面全体の効果
- 画像と文字の UI (日本語のフォントを含む)
- 当たり判定 (球・箱、レイヤー、レイキャスト) と、キーボード・マウス・パッドの入力
- 効果音と BGM (3D の音を含む)
- エディター画面での値の調整と保存 (PropertyBinder)、パーティクルのエディター
- 開発用のエラー表示・ログ・デバッグ描画・デバッグカメラ

### はじめ方
- `Template/` のひな形から始める。手順は `Docs/start/new-project.md`
- エンジンの更新は `UpdateEngine.ps1`。使い方は `README.md`
- 完成版のまとめ方は `Docs/guides/packaging.md`
